## 2026-08-08 - Fast Z3Translator Hierarchy Lookups
**Learning:** In symbolic translation where each trace record is processed individually, computing reverse mappings inside an innermost loop causes significant overhead. The original `Z3Translator` mapped registers to their base counterpart (e.g., `eax` -> `rax`) using a nested loop scan over `REGISTER_HIERARCHY` items within `_read_operand` and `_write_operand`. This is costly since these methods are called heavily per instruction translated.
**Action:** Replace $O(N)$ linear scans over hierarchical mappings with an $O(1)$ reverse lookup hashmap that is precomputed once (e.g. during object initialization). Always favor precomputed $O(1)$ lookups for operations occurring on a hot path like single instruction processing or property lookup.
