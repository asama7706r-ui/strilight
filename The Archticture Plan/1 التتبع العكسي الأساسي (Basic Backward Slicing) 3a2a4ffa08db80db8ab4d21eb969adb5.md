# 1. التتبع العكسي الأساسي (Basic Backward Slicing)

يعتمد نظامنا على "التنفيذ الديناميكي الملموس" (Concrete Dynamic Execution) لحل الشروط دون تزوير الذاكرة، عبر الخطوات التالية:

- **العكس الرياضي:** عند الاصطدام بشرط، نتراجع تعليمة تلو الأخرى، مع تطبيق "المعكوس الرياضي" (Algebraic Inversion) لكل عملية لمعرفة القيمة السابقة.
- **نقطة الإدخال (Input Boundary):** يستمر التراجع حتى الاصطدام بنقطة إدخال خارجية يمكن التحكم بها (API أو Memory Buffer).
- **التقليم التلقائي (Implicit Pruning):** أثناء التراجع، سيصطدم المحرك بمسارات مستحيلة رياضياً، مما يؤدي إلى تقليم الاحتمالات وحصر فضاء البحث بشكل طبيعي وفعال.
